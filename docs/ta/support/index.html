ஏதாவது வேலை செய்யவில்லையா?

எதுவும் மறைக்கப்படவில்லை

எப்போதுமே ஏறக்குறைய இந்த நான்கில் ஒன்றுதான் காரணம், இதே வரிசையில்.

  1. இப்போதுதான் நிறுவினீர்கள் அல்லது புதுப்பித்தீர்கள் என்றால், ஏற்கனவே திறந்திருந்த YouTube தாவல்களை மீண்டும் ஏற்றவும்

    Chrome நிறுவப்பட்ட பிறகு திறக்கப்பட்ட பக்கங்களில் மட்டுமே ஒரு நீட்டிப்பை இயக்குகிறது, எனவே ஏற்கனவே திறந்திருந்த YouTube தாவலில், நீங்கள் அதை மீண்டும் ஏற்றும் வரை FocusTube சிறிதும் இல்லை. நீட்டிப்பு புதுப்பிக்கப்பட்ட உடனேயும் இதே நிலைமைதான்.

    ஒருமுறை இயங்கத் தொடங்கிய பிறகு, தொடர்ந்து மீண்டும் ஏற்ற வேண்டியதில்லை: எதையாவது இயக்குவது அல்லது நிறுத்துவது திறந்த தாவல்களில் உடனடியாக நடைமுறைக்கு வரும்.

  2. பயன்முறை ஆஃப் இல் இல்லை என்பதைச் சரிபார்க்கவும்

    பாப்அப்பைத் திறந்து பயன்முறை தாவலைப் பாருங்கள். ஆஃப் இல், Settings இல் என்ன இயக்கப்பட்டிருந்தாலும், YouTube இல் அனைத்தும் வேண்டுமென்றே காட்டப்படும். எதை மறைக்க வேண்டும் என்பதை Settings தீர்மானிக்கிறது; அது எப்போது நடைமுறைக்கு வரும் என்பதை Mode தீர்மானிக்கிறது.

  3. Timer இல், உண்மையிலேயே ஒரு அமர்வு இயங்குகிறதா எனச் சரிபார்க்கவும்

    இதுதான் அதிகமான பேரைக் குழப்பும். Timer ஐத் தேர்ந்தெடுப்பது தானாகவே எதையும் தொடங்காது — இதன் பொருள் "கவனம் அமர்வு இயங்கும்போது மட்டும் விஷயங்களை மறை" என்பதே. நீங்கள் தொடங்கு அழுத்தும் வரை, எந்த அமர்வும் இயங்காது, எனவே எதுவும் மறைக்கப்படாது, நீட்டிப்பு உடைந்ததாகத் தெரியும்.

    ஒரு அமர்வைத் தொடங்குங்கள், அல்லது உங்கள் அமைப்புகள் எப்போதும் நடைமுறையில் இருக்க வேண்டும் என்றால் பயன்முறையை எப்போதும் என மாற்றுங்கள்.

  4. Schedule இல், உங்கள் நேரக் கட்டங்களில் ஒன்றுக்குள் இருக்கிறீர்களா எனச் சரிபார்க்கவும்

    அதே கருத்து. நீங்கள் அமைத்த நாட்கள் மற்றும் நேரங்களில் மட்டுமே Schedule நடைமுறைக்கு வரும், எனவே அந்தக் கட்டங்களுக்கு வெளியே YouTube வேண்டுமென்றே தொடாமல் விடப்படுகிறது. இன்று சனிக்கிழமையாக இருந்து உங்கள் schedule வார நாட்களை மட்டுமே உள்ளடக்கியிருந்தால், எதுவும் மறைக்கப்படாது — அது கட்டமைக்கப்பட்டபடியே செயல்படுகிறது என்று பொருள்.

இது எப்போதும் நிரந்தரமாக இயங்க வேண்டும் என்றும் இதைப் பற்றி மீண்டும் யோசிக்கக் கூடாது என்றும் நீங்கள் விரும்பினால், பயன்முறையை எப்போதும் எனச் சரிசெய்யுங்கள்.

வேலை செய்து கொண்டிருந்த ஒரு அமைப்பு திடீரென நிறுத்தியது

YouTube தன் சொந்தப் பக்க அமைப்பை அடிக்கடி மாற்றுகிறது, அவர்கள் தரப்பில் ஏற்படும் மாற்றம் ஏதேனும் ஒரு டாக்கிள் அது மறைக்க வேண்டியதைக் கண்டறியாமல் போகச் செய்யலாம். மற்றவை வேலை செய்து கொண்டிருக்கும்போது ஒரே ஒரு அம்சம் மட்டும் உடைந்தால் இதுவே மிகவும் சாத்தியமான காரணம்.

காத்திருப்பதை விட இதைத் தெரிவிப்பது நல்லது — YouTube இன் எந்தப் பகுதி மாறியது என யாரேனும் அறிந்தவுடன் பொதுவாக இது விரைவாக சரி செய்யப்படும். நீங்கள் என்ன பார்த்துக் கொண்டிருந்தீர்கள், எந்த டாக்கிள் வேலை செய்யாமல் போனது என்பதைக் குறிப்பிடுங்கள்.

GitHub இல் தெரிவிக்கவும்

சிறிது நேரத்திற்கு வழக்கமான YouTube ஐத் திரும்பப் பெற விரும்புகிறீர்கள்

நீக்க வேண்டியதோ அல்லது ஒவ்வொன்றாக அணைக்க வேண்டியதோ இல்லை. பாப்அப்பைத் திறந்து, Mode க்குச் சென்று ஆஃப் ஐத் தேர்ந்தெடுக்கவும். YouTube இல் அனைத்தும் மீண்டும் தோன்றும், நீங்கள் மீண்டும் இயக்கும் வரை உங்கள் அமைப்புகள் மற்றும் தடுப்பு பட்டியல்கள் அனைத்தும் நீங்கள் விட்டுச் சென்றபடியே இருக்கும்.

FocusTube என்ன பார்க்க முடியும்

இது YouTube பக்கங்களில் மட்டுமே இயங்குகிறது, இரண்டு அனுமதிகளைக் கோருகிறது: உங்கள் அமைப்புகளை நினைவில் வைக்க storage, மற்றும் Focus Mode இன் டைமர்கள் மற்றும் அட்டவணைகளுக்கு alarms. கணக்கு எதுவும் இல்லை, எதுவும் எங்கும் அனுப்பப்படுவதில்லை, உங்கள் உலாவல் பற்றி எதுவும் சேகரிக்கப்படுவதில்லை.

முழு நீட்டிப்பும் ஓபன் சோர்ஸ், எனவே இது வெறும் வாக்குறுதி அல்ல, சரிபார்க்கக்கூடியது — குறியீட்டைப் படியுங்கள்.

இன்னும் சிக்கியிருக்கிறீர்களா

GitHub இல் ஒரு issue ஐத் திறந்து, நீங்கள் எதை எதிர்பார்த்தீர்கள், அதற்குப் பதிலாக என்ன நடந்தது என்பதை விவரிக்கவும். உங்கள் உலாவி பதிப்பையும், Windows, macOS அல்லது Linux பயன்படுத்துகிறீர்களா என்பதையும் குறிப்பிடுவது பொதுவாக ஒரு கூடுதல் கேள்வி பதிலைச் சேமிக்கும்.
