કંઈક કામ નથી કરી રહ્યું?

પહેલા મુદ્દાથી શરૂ કરો. તે મોટાભાગના કિસ્સા ઉકેલે છે અને તપાસવામાં એક સેકન્ડ લે છે.

આ પેજ પર

  • કંઈ છુપાવવામાં આવતું નથી
  • એક સેટિંગ જે કામ કરતું હતું તે અચાનક બંધ થઈ ગયું
  • તમે થોડા સમય માટે સામાન્ય YouTube પાછું ઇચ્છો છો
  • FocusTube શું જોઈ શકે છે
  • હજુ પણ અટવાયેલા છો

કંઈ છુપાવવામાં આવતું નથી

લગભગ હંમેશા આ ચારમાંથી એક કારણ હોય છે, આ ક્રમમાં.

  1. જો તમે હમણાં જ ઇન્સ્ટોલ કે અપડેટ કર્યું હોય, તો પહેલેથી ખુલ્લા YouTube ટૅબ ફરીથી લોડ કરો

    Chrome એક્સટેન્શનને ફક્ત તે પેજ પર ચલાવે છે જે તેને ઇન્સ્ટોલ કર્યા પછી ખોલવામાં આવ્યા હોય, તેથી પહેલેથી ખુલ્લું YouTube ટૅબ તમે તેને ફરીથી લોડ ન કરો ત્યાં સુધી બિલકુલ FocusTube ધરાવતું નથી. એક્સટેન્શન અપડેટ થયા પછી તરત જ પણ આવું જ થાય છે.

    એકવાર તે ચાલવા લાગે પછી તમારે વારંવાર રિલોડ કરવાની જરૂર નથી: કંઈક ચાલુ કે બંધ કરવું ખુલ્લા ટૅબ પર તરત જ લાગુ થાય છે.

  2. તપાસો કે મોડ બંધ પર તો નથી

    પોપઅપ ખોલો અને મોડ ટૅબ જુઓ. બંધ પર, Settings માં ગમે તે ચાલુ હોય, YouTube પર જાણી જોઈને બધું જ બતાવવામાં આવે છે. Settings નક્કી કરે છે કે શું છુપાવવું; Mode નક્કી કરે છે કે તે ક્યારે લાગુ થાય.

  3. Timer માં, તપાસો કે ખરેખર કોઈ સેશન ચાલી રહ્યું છે

    આ સૌથી વધુ લોકોને મૂંઝવે છે. Timer પસંદ કરવાથી પોતાની મેળે કંઈ શરૂ થતું નથી — તેનો અર્થ ફક્ત એટલો જ છે કે "જ્યાં સુધી ફોકસ સેશન ચાલી રહ્યું હોય ત્યાં સુધી વસ્તુઓ છુપાવો". જ્યાં સુધી તમે સ્ટાર્ટ ન દબાવો, ત્યાં સુધી કોઈ સેશન ચાલતું નથી, તેથી કંઈ છુપાવવામાં આવતું નથી અને એક્સટેન્શન તૂટેલું લાગે છે.

    કાં તો સેશન શરૂ કરો, અથવા જો તમે ઇચ્છો કે તમારી સેટિંગ્સ હંમેશા લાગુ રહે તો મોડને હંમેશા પર બદલો.

  4. Schedule માં, તપાસો કે તમે તમારા સમય-ગાળામાંથી એકની અંદર છો

    એ જ વિચાર. Schedule ફક્ત તમે નક્કી કરેલા દિવસો અને સમય પર જ લાગુ થાય છે, તેથી તે સમય-ગાળાની બહાર YouTube ને જાણી જોઈને એમ જ છોડી દેવામાં આવે છે. જો આજે શનિવાર હોય અને તમારું schedule ફક્ત કામકાજના દિવસો આવરી લેતું હોય, તો કંઈ છુપાવવામાં આવશે નહીં — તેનો અર્થ એ કે તે ગોઠવણી પ્રમાણે જ કામ કરી રહ્યું છે.

જો તમે ફક્ત એટલું જ ઇચ્છો છો કે તે કાયમ માટે ચાલુ રહે અને ફરી ક્યારેય તેના વિશે વિચારવું ન પડે, તો મોડને હંમેશા પર સેટ કરો.

એક સેટિંગ જે કામ કરતું હતું તે અચાનક બંધ થઈ ગયું

YouTube પોતાના પેજની રચના ઘણી વાર બદલે છે, અને તેમના તરફથી થયેલો ફેરફાર કોઈ એક ટૉગલને તે જે છુપાવવાનું હોય તે શોધવાથી રોકી શકે છે. જ્યારે બાકીના બધા કામ કરતા રહે અને ફક્ત એક જ ફીચર તૂટે, ત્યારે આ સૌથી સંભવિત કારણ છે.

રાહ જોવાને બદલે તેની જાણ કરવી યોગ્ય છે — સામાન્ય રીતે, YouTube નો કયો ભાગ બદલાયો છે તે કોઈને ખબર પડતાં જ તે ઝડપથી ઠીક થઈ જાય છે. તમે શું જોઈ રહ્યા હતા અને કયું ટૉગલ કામ કરવાનું બંધ થયું તે જણાવો.

GitHub પર જણાવો

તમે થોડા સમય માટે સામાન્ય YouTube પાછું ઇચ્છો છો

તમારે અનઇન્સ્ટોલ કરવાની કે બધું એક પછી એક બંધ કરવાની જરૂર નથી. પોપઅપ ખોલો, Mode પર જાઓ અને બંધ પસંદ કરો. YouTube પર બધું ફરીથી દેખાવા લાગે છે, અને તમારી બધી સેટિંગ્સ અને બ્લોકલિસ્ટ તમે તેને જ્યાં છોડી હતી ત્યાં જ, ફરીથી ચાલુ કરો ત્યાં સુધી, બરાબર એ જ રીતે રહે છે.

FocusTube શું જોઈ શકે છે

તે ફક્ત YouTube પેજ પર જ ચાલે છે, અને બે પરવાનગીઓ માંગે છે: તમારી સેટિંગ્સ યાદ રાખવા માટે storage, અને Focus Mode ના ટાઈમર અને શેડ્યૂલ માટે alarms. કોઈ એકાઉન્ટ નથી, ક્યાંય કંઈ મોકલવામાં આવતું નથી, અને તમારા બ્રાઉઝિંગ વિશે કંઈ એકત્રિત કરવામાં આવતું નથી.

આખું એક્સટેન્શન ઓપન સોર્સ છે, તેથી આ ફક્ત વચન નહીં પણ ચકાસી શકાય તેવું છે — કોડ વાંચો.

હજુ પણ અટવાયેલા છો

GitHub પર એક issue ખોલો અને વર્ણવો કે તમે શું અપેક્ષા રાખી હતી અને તેના બદલે શું થયું. તમારા બ્રાઉઝરનું વર્ઝન અને તમે Windows, macOS કે Linux વાપરો છો તે જણાવવાથી સામાન્ય રીતે એક વધારાનો સવાલ-જવાબ બચી જાય છે.
