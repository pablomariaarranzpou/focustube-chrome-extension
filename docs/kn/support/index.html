ಏನಾದರೂ ಕೆಲಸ ಮಾಡುತ್ತಿಲ್ಲವೇ?

ಮೊದಲನೆಯದರಿಂದ ಪ್ರಾರಂಭಿಸಿ. ಇದು ಹೆಚ್ಚಿನ ಸಂದರ್ಭಗಳನ್ನು ಪರಿಹರಿಸುತ್ತದೆ ಮತ್ತು ಪರಿಶೀಲಿಸಲು ಒಂದು ಸೆಕೆಂಡ್ ತೆಗೆದುಕೊಳ್ಳುತ್ತದೆ.

ಈ ಪುಟದಲ್ಲಿ

  • ಏನನ್ನೂ ಮರೆಮಾಡಲಾಗುತ್ತಿಲ್ಲ
  • ಕೆಲಸ ಮಾಡುತ್ತಿದ್ದ ಸೆಟ್ಟಿಂಗ್ ಇದ್ದಕ್ಕಿದ್ದಂತೆ ನಿಂತುಹೋಯಿತು
  • ಸ್ವಲ್ಪ ಸಮಯದವರೆಗೆ ಸಾಮಾನ್ಯ YouTube ಅನ್ನು ಮತ್ತೆ ಪಡೆಯಲು ಬಯಸುತ್ತೀರಿ
  • FocusTube ಏನನ್ನು ನೋಡಬಹುದು
  • ಇನ್ನೂ ಸಿಲುಕಿದ್ದೀರಾ

ಏನನ್ನೂ ಮರೆಮಾಡಲಾಗುತ್ತಿಲ್ಲ

ಬಹುತೇಕ ಯಾವಾಗಲೂ ಈ ನಾಲ್ಕರಲ್ಲಿ ಒಂದು ಕಾರಣ, ಈ ಕ್ರಮದಲ್ಲಿ.

  1. ನೀವು ಇದೀಗ ಇನ್‌ಸ್ಟಾಲ್ ಅಥವಾ ಅಪ್‌ಡೇಟ್ ಮಾಡಿದ್ದರೆ, ಈಗಾಗಲೇ ತೆರೆದಿದ್ದ YouTube ಟ್ಯಾಬ್‌ಗಳನ್ನು ಮರುಲೋಡ್ ಮಾಡಿ

    Chrome ಎಕ್ಸ್‌ಟೆನ್ಶನ್ ಅನ್ನು ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡಿದ ನಂತರ ತೆರೆದ ಪುಟಗಳಲ್ಲಿ ಮಾತ್ರ ಚಲಾಯಿಸುತ್ತದೆ, ಆದ್ದರಿಂದ ಈಗಾಗಲೇ ತೆರೆದಿದ್ದ YouTube ಟ್ಯಾಬ್‌ನಲ್ಲಿ ನೀವು ಅದನ್ನು ಮರುಲೋಡ್ ಮಾಡುವವರೆಗೆ FocusTube ಇರುವುದೇ ಇಲ್ಲ. ಎಕ್ಸ್‌ಟೆನ್ಶನ್ ಅಪ್‌ಡೇಟ್ ಆದ ತಕ್ಷಣವೇ ಇದೇ ಅನ್ವಯಿಸುತ್ತದೆ.

    ಒಮ್ಮೆ ಅದು ಚಾಲನೆಯಲ್ಲಿದ್ದರೆ, ನೀವು ಮತ್ತೆ ಮತ್ತೆ ಮರುಲೋಡ್ ಮಾಡಬೇಕಾಗಿಲ್ಲ: ಏನನ್ನಾದರೂ ಆನ್ ಅಥವಾ ಆಫ್ ಮಾಡುವುದು ತೆರೆದ ಟ್ಯಾಬ್‌ಗಳಲ್ಲಿ ತಕ್ಷಣ ಅನ್ವಯವಾಗುತ್ತದೆ.

  2. ಮೋಡ್ ಆಫ್ ನಲ್ಲಿ ಇಲ್ಲ ಎಂದು ಪರಿಶೀಲಿಸಿ

    ಪಾಪ್‌ಅಪ್ ತೆರೆದು ಮೋಡ್ ಟ್ಯಾಬ್ ನೋಡಿ. ಆಫ್ ನಲ್ಲಿ, Settings ನಲ್ಲಿ ಏನೇ ಆನ್ ಇದ್ದರೂ, YouTube ನಲ್ಲಿ ಎಲ್ಲವನ್ನೂ ಉದ್ದೇಶಪೂರ್ವಕವಾಗಿ ತೋರಿಸಲಾಗುತ್ತದೆ. Settings ಏನನ್ನು ಮರೆಮಾಡಬೇಕು ಎಂಬುದನ್ನು ನಿರ್ಧರಿಸುತ್ತದೆ; Mode ಅದು ಯಾವಾಗ ಅನ್ವಯಿಸುತ್ತದೆ ಎಂಬುದನ್ನು ನಿರ್ಧರಿಸುತ್ತದೆ.

  3. Timer ನಲ್ಲಿ, ನಿಜವಾಗಿಯೂ ಸೆಷನ್ ಚಾಲನೆಯಲ್ಲಿದೆಯೇ ಎಂದು ಪರಿಶೀಲಿಸಿ

    ಇದು ಹೆಚ್ಚಿನ ಜನರನ್ನು ಗೊಂದಲಗೊಳಿಸುತ್ತದೆ. Timer ಆಯ್ಕೆಮಾಡುವುದರಿಂದ ಸ್ವತಃ ಏನೂ ಪ್ರಾರಂಭವಾಗುವುದಿಲ್ಲ — ಇದರ ಅರ್ಥ ಕೇವಲ "ಫೋಕಸ್ ಸೆಷನ್ ಚಾಲನೆಯಲ್ಲಿರುವವರೆಗೆ ವಿಷಯಗಳನ್ನು ಮರೆಮಾಡಿ" ಎಂದಷ್ಟೇ. ನೀವು ಸ್ಟಾರ್ಟ್ ಒತ್ತುವವರೆಗೆ, ಯಾವುದೇ ಸೆಷನ್ ಚಾಲನೆಯಲ್ಲಿಲ್ಲ, ಆದ್ದರಿಂದ ಏನನ್ನೂ ಮರೆಮಾಡಲಾಗುವುದಿಲ್ಲ ಮತ್ತು ಎಕ್ಸ್‌ಟೆನ್ಶನ್ ಮುರಿದಂತೆ ಕಾಣುತ್ತದೆ.

    ಒಂದೋ ಸೆಷನ್ ಪ್ರಾರಂಭಿಸಿ, ಅಥವಾ ನಿಮ್ಮ ಸೆಟ್ಟಿಂಗ್‌ಗಳು ಯಾವಾಗಲೂ ಅನ್ವಯವಾಗಬೇಕೆಂದು ಬಯಸಿದರೆ ಮೋಡ್ ಅನ್ನು ಯಾವಾಗಲೂ ಗೆ ಬದಲಾಯಿಸಿ.

  4. Schedule ನಲ್ಲಿ, ನೀವು ನಿಮ್ಮ ಸಮಯದ ಅವಧಿಗಳಲ್ಲಿ ಒಂದರೊಳಗೆ ಇದ್ದೀರಾ ಎಂದು ಪರಿಶೀಲಿಸಿ

    ಅದೇ ಆಲೋಚನೆ. Schedule ನೀವು ಹೊಂದಿಸಿದ ದಿನಗಳು ಮತ್ತು ಸಮಯಗಳಲ್ಲಿ ಮಾತ್ರ ಅನ್ವಯಿಸುತ್ತದೆ, ಆದ್ದರಿಂದ ಆ ಅವಧಿಗಳ ಹೊರಗೆ YouTube ಅನ್ನು ಉದ್ದೇಶಪೂರ್ವಕವಾಗಿ ಹಾಗೆಯೇ ಬಿಡಲಾಗುತ್ತದೆ. ಇಂದು ಶನಿವಾರವಾಗಿದ್ದು ನಿಮ್ಮ schedule ಕೇವಲ ವಾರದ ದಿನಗಳನ್ನು ಒಳಗೊಂಡಿದ್ದರೆ, ಏನನ್ನೂ ಮರೆಮಾಡಲಾಗುವುದಿಲ್ಲ — ಇದರರ್ಥ ಅದು ಕಾನ್ಫಿಗರ್ ಮಾಡಿದಂತೆಯೇ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತಿದೆ.

ಇದು ಶಾಶ್ವತವಾಗಿ ಆನ್ ಆಗಿರಬೇಕು ಮತ್ತು ಇದರ ಬಗ್ಗೆ ಮತ್ತೆಂದೂ ಯೋಚಿಸಬಾರದು ಎಂದು ನೀವು ಬಯಸಿದರೆ, ಮೋಡ್ ಅನ್ನು ಯಾವಾಗಲೂ ಗೆ ಹೊಂದಿಸಿ.

ಕೆಲಸ ಮಾಡುತ್ತಿದ್ದ ಸೆಟ್ಟಿಂಗ್ ಇದ್ದಕ್ಕಿದ್ದಂತೆ ನಿಂತುಹೋಯಿತು

YouTube ತನ್ನ ಸ್ವಂತ ಪುಟಗಳ ರಚನೆಯನ್ನು ಸಾಕಷ್ಟು ಬಾರಿ ಬದಲಾಯಿಸುತ್ತದೆ, ಮತ್ತು ಅವರ ಕಡೆಯಿಂದ ಆಗುವ ಬದಲಾವಣೆಯು ಟಾಗಲ್‌ಗಳಲ್ಲಿ ಒಂದು ಅದು ಮರೆಮಾಡಬೇಕಾದದ್ದನ್ನು ಕಂಡುಹಿಡಿಯುವುದನ್ನು ನಿಲ್ಲಿಸಬಹುದು. ಉಳಿದವು ಕೆಲಸ ಮಾಡುತ್ತಿರುವಾಗ ಒಂದೇ ಫೀಚರ್ ಮುರಿದಾಗ ಇದು ಅತ್ಯಂತ ಸಂಭವನೀಯ ಕಾರಣ.

ಕಾಯುವ ಬದಲು ಇದನ್ನು ವರದಿ ಮಾಡುವುದು ಯೋಗ್ಯವಾಗಿದೆ — YouTube ನ ಯಾವ ಭಾಗ ಬದಲಾಗಿದೆ ಎಂದು ಯಾರಿಗಾದರೂ ತಿಳಿದ ತಕ್ಷಣ ಸಾಮಾನ್ಯವಾಗಿ ಇದನ್ನು ತ್ವರಿತವಾಗಿ ಸರಿಪಡಿಸಲಾಗುತ್ತದೆ. ನೀವು ಏನನ್ನು ನೋಡುತ್ತಿದ್ದೀರಿ ಮತ್ತು ಯಾವ ಟಾಗಲ್ ಕೆಲಸ ಮಾಡುವುದನ್ನು ನಿಲ್ಲಿಸಿತು ಎಂಬುದನ್ನು ಸೇರಿಸಿ.

GitHub ನಲ್ಲಿ ವರದಿ ಮಾಡಿ

ಸ್ವಲ್ಪ ಸಮಯದವರೆಗೆ ಸಾಮಾನ್ಯ YouTube ಅನ್ನು ಮತ್ತೆ ಪಡೆಯಲು ಬಯಸುತ್ತೀರಿ

ಅನ್‌ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡುವ ಅಥವಾ ಎಲ್ಲವನ್ನೂ ಒಂದೊಂದಾಗಿ ಆಫ್ ಮಾಡುವ ಅಗತ್ಯವಿಲ್ಲ. ಪಾಪ್‌ಅಪ್ ತೆರೆಯಿರಿ, Mode ಗೆ ಹೋಗಿ ಮತ್ತು ಆಫ್ ಆಯ್ಕೆಮಾಡಿ. YouTube ನಲ್ಲಿ ಎಲ್ಲವೂ ಮತ್ತೆ ಕಾಣಿಸಿಕೊಳ್ಳುತ್ತದೆ, ಮತ್ತು ನೀವು ಮತ್ತೆ ಆನ್ ಮಾಡುವವರೆಗೆ ನಿಮ್ಮ ಎಲ್ಲಾ ಸೆಟ್ಟಿಂಗ್‌ಗಳು ಮತ್ತು ಬ್ಲಾಕ್‌ಲಿಸ್ಟ್‌ಗಳು ನೀವು ಬಿಟ್ಟಂತೆಯೇ ಇರುತ್ತವೆ.

FocusTube ಏನನ್ನು ನೋಡಬಹುದು

ಇದು YouTube ಪುಟಗಳಲ್ಲಿ ಮಾತ್ರ ಚಲಿಸುತ್ತದೆ, ಮತ್ತು ಎರಡು ಅನುಮತಿಗಳನ್ನು ಕೇಳುತ್ತದೆ: ನಿಮ್ಮ ಸೆಟ್ಟಿಂಗ್‌ಗಳನ್ನು ನೆನಪಿಟ್ಟುಕೊಳ್ಳಲು storage, ಮತ್ತು Focus Mode ನ ಟೈಮರ್‌ಗಳು ಮತ್ತು ಶೆಡ್ಯೂಲ್‌ಗಳಿಗಾಗಿ alarms. ಯಾವುದೇ ಖಾತೆ ಇಲ್ಲ, ಎಲ್ಲಿಗೂ ಏನೂ ಕಳುಹಿಸಲಾಗುವುದಿಲ್ಲ, ಮತ್ತು ನಿಮ್ಮ ಬ್ರೌಸಿಂಗ್ ಬಗ್ಗೆ ಏನನ್ನೂ ಸಂಗ್ರಹಿಸಲಾಗುವುದಿಲ್ಲ.

ಇಡೀ ಎಕ್ಸ್‌ಟೆನ್ಶನ್ ಓಪನ್ ಸೋರ್ಸ್ ಆಗಿದೆ, ಆದ್ದರಿಂದ ಇದು ಕೇವಲ ಭರವಸೆಯಲ್ಲ, ಪರಿಶೀಲಿಸಬಹುದಾಗಿದೆ — ಕೋಡ್ ಓದಿ.

ಇನ್ನೂ ಸಿಲುಕಿದ್ದೀರಾ

GitHub ನಲ್ಲಿ issue ತೆರೆಯಿರಿ ಮತ್ತು ನೀವು ಏನನ್ನು ನಿರೀಕ್ಷಿಸಿದ್ದೀರಿ ಮತ್ತು ಬದಲಿಗೆ ಏನಾಯಿತು ಎಂಬುದನ್ನು ವಿವರಿಸಿ. ನಿಮ್ಮ ಬ್ರೌಸರ್ ಆವೃತ್ತಿಯನ್ನು ಮತ್ತು ನೀವು Windows, macOS ಅಥವಾ Linux ಬಳಸುತ್ತೀರಾ ಎಂಬುದನ್ನು ಉಲ್ಲೇಖಿಸುವುದು ಸಾಮಾನ್ಯವಾಗಿ ಹೆಚ್ಚುವರಿ ಪ್ರಶ್ನೋತ್ತರವನ್ನು ಉಳಿಸುತ್ತದೆ.
