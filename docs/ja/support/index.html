何か動作しませんか？

まずは最初の項目から確認してください。ほとんどの場合はこれで解決し、確認も一瞬で済みます。

何も非表示になっていない

ほとんどの場合、この順番で次の4つのいずれかが原因です。

  1. インストールまたは更新した直後の場合は、すでに開いていたYouTubeのタブを再読み込みしてください

    ChromeはインストールされたAFTERに開かれたページでしか拡張機能を実行しないため、すでに開いていたYouTubeのタブには、再読み込みするまでFocusTubeがまったく存在しません。拡張機能が更新された直後も同様です。

    一度動き始めれば、常に再読み込みする必要はありません。設定のオン・オフは開いているタブに即座に反映されます。

  2. モードがオフになっていないか確認してください

    ポップアップを開き、モードタブを確認してください。オフの場合、設定で何がオンになっていても関係なく、YouTubeにはすべて意図的に表示されます。設定は何を非表示にするかを決め、モードはいつそれが適用されるかを決めます。

  3. タイマーでは、実際にセッションが実行中か確認してください

    これが一番誤解されやすいポイントです。タイマーを選択しただけでは何も始まりません——「集中セッションが実行中の間だけ物事を非表示にする」という意味でしかないのです。開始を押すまでセッションは実行されておらず、そのため何も非表示にならず、拡張機能が壊れているように見えます。

    セッションを開始するか、設定を常に適用したい場合はモードを常時に切り替えてください。

  4. スケジュールでは、設定した時間帯の中にいるか確認してください

    考え方は同じです。スケジュールは設定した曜日と時間にしか適用されないため、その時間帯の外ではYouTubeは意図的にそのままにされます。今日が土曜日でスケジュールが平日しかカバーしていない場合、何も非表示になりません——それは設定通りに動作しているということです。

とにかく常にオンにしておき、二度とこれについて考えたくない場合は、モードを常時に設定してください。

動いていた設定が突然止まった

YouTubeは自分のページ構造をかなり頻繁に変更しており、その変更によって、いずれかのトグルが非表示にすべきものを見つけられなくなることがあります。他の機能は動いているのに1つの機能だけ壊れた場合、これが最も可能性の高い原因です。

待つよりも報告する価値があります——YouTubeのどの部分が変わったかがわかれば、たいていすぐに修正されます。何を見ていたか、どのトグルが動かなくなったかを記載してください。

GitHubで報告する

しばらく通常のYouTubeに戻したい

アンインストールしたり、一つずつオフにしたりする必要はありません。ポップアップを開き、モードに移動してオフを選択してください。YouTubeにはすべてが再び表示され、設定やブロックリストはすべて、再度オンにするまで、あなたが残した状態のまま保持されます。

FocusTubeが見られる情報

YouTubeのページでのみ動作し、2つの権限を要求します。設定を記憶するためのstorageと、フォーカスモードのタイマーとスケジュールのためのalarmsです。アカウントはなく、どこにも何も送信されず、閲覧履歴について何も収集されません。

拡張機能全体がオープンソースなので、約束ではなく確認可能です——コードを読む。

それでも解決しない

GitHubでissueを開き、期待していたことと実際に起きたことを説明してください。ブラウザのバージョンと、Windows、macOS、Linuxのどれを使っているかを記載すると、たいてい一往復のやり取りを省けます。
