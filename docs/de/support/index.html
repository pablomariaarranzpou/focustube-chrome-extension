Es wird nichts ausgeblendet

Fast immer ist es einer dieser vier Gründe, in dieser Reihenfolge.

  1. Falls du es gerade installiert oder aktualisiert hast: lade die bereits geöffneten YouTube-Tabs neu

    Chrome führt eine Erweiterung nur auf Seiten aus, die nach der Installation geöffnet wurden — ein bereits geöffneter YouTube-Tab enthält also gar kein FocusTube, bis du ihn neu lädst. Dasselbe gilt direkt nach einem Update der Erweiterung.

    Sobald sie läuft, musst du nicht ständig neu laden: Ein- oder Ausschalten wirkt sich sofort auf geöffnete Tabs aus.

  2. Prüfe, dass der Modus nicht auf Aus steht

    Öffne das Popup und schau auf den Tab Modus. Bei Aus wird auf YouTube absichtlich alles angezeigt, egal was in den Einstellungen aktiviert ist. Die Einstellungen bestimmen, was ausgeblendet wird; der Modus bestimmt, wann das gilt.

  3. Bei Timer prüfen, ob wirklich eine Sitzung läuft

    Das ist der Punkt, an dem die meisten hängen bleiben. Timer auszuwählen startet von selbst gar nichts — es bedeutet nur „Dinge ausblenden, solange eine Fokus-Sitzung läuft“. Bis du auf Start drückst, läuft keine Sitzung, also wird nichts ausgeblendet und die Erweiterung wirkt kaputt.

    Starte entweder eine Sitzung oder stelle den Modus auf Immer, wenn deine Einstellungen dauerhaft gelten sollen.

  4. Bei Zeitplan prüfen, ob du gerade in einem deiner Zeitfenster bist

    Gleicher Gedanke. Ein Zeitplan gilt nur an den festgelegten Tagen und Uhrzeiten, außerhalb davon bleibt YouTube absichtlich unverändert. Ist heute Samstag und dein Zeitplan deckt nur Werktage ab, wird nichts ausgeblendet — genau so soll es funktionieren.

Wenn es einfach dauerhaft aktiv sein soll und du nie wieder darüber nachdenken willst, stelle den Modus auf Immer.

Eine Einstellung funktionierte und hörte plötzlich auf

YouTube ändert recht häufig die Struktur seiner eigenen Seiten, und eine Änderung auf deren Seite kann dazu führen, dass einer der Schalter nicht mehr findet, was er ausblenden soll. Das ist die wahrscheinlichste Ursache, wenn eine einzelne Funktion ausfällt, während der Rest weiterhin funktioniert.

Es lohnt sich, es zu melden statt zu warten — sowas ist meist schnell behoben, sobald jemand weiß, welcher Teil von YouTube sich geändert hat. Gib an, was du dir angesehen hast und welcher Schalter aufgehört hat zu funktionieren.

Du willst das normale YouTube für eine Weile zurück

Du musst nicht deinstallieren oder alles einzeln ausschalten. Öffne das Popup, geh zu Modus und wähle Aus. Auf YouTube wird wieder alles angezeigt, und alle deine Einstellungen und Sperrlisten bleiben genau so erhalten, wie du sie verlassen hast, für wenn du wieder umschaltest.

Was FocusTube sehen kann

Es läuft nur auf YouTube-Seiten und fragt nach zwei Berechtigungen: storage, um deine Einstellungen zu speichern, und alarms, für die Timer und Zeitpläne des Fokusmodus. Es gibt kein Konto, es wird nichts irgendwohin gesendet, und nichts über dein Surfverhalten wird erfasst.

Die gesamte Erweiterung ist Open Source, das lässt sich also nachprüfen statt nur versprochen zu werden — den Code ansehen.

Immer noch nicht weiter

Erstelle ein Issue auf GitHub und beschreibe, was du erwartet hast und was stattdessen passiert ist. Die Angabe deiner Browserversion und ob du Windows, macOS oder Linux nutzt, erspart meist eine Rückfrage.
