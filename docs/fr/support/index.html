Rien n'est masqué

C'est presque toujours l'un de ces quatre cas, dans cet ordre.

  1. Si vous venez de l'installer ou de le mettre à jour, rechargez les onglets YouTube déjà ouverts

    Chrome n'exécute une extension que sur les pages ouvertes après son installation : un onglet YouTube déjà ouvert ne contient donc aucun FocusTube tant que vous ne le rechargez pas. C'est pareil juste après une mise à jour de l'extension.

    Une fois en marche, plus besoin de recharger sans cesse : activer ou désactiver un réglage s'applique immédiatement aux onglets ouverts.

  2. Vérifiez que le mode n'est pas sur Désactivé

    Ouvrez le popup et regardez l'onglet Mode. Sur Désactivé, tout s'affiche sur YouTube volontairement, quoi que vous ayez activé dans les Réglages. Les Réglages décident ce qui est masqué ; le Mode décide quand cela s'applique.

  3. En mode Minuteur, vérifiez qu'une session est bien en cours

    C'est celui qui piège le plus de monde. Choisir Minuteur ne démarre rien tout seul — cela signifie seulement « masquer les éléments pendant qu'une session de concentration est en cours ». Tant que vous n'avez pas appuyé sur démarrer, aucune session ne tourne, donc rien n'est masqué et l'extension semble cassée.

    Démarrez une session, ou basculez le mode sur Toujours si vous voulez que vos réglages s'appliquent en permanence.

  4. En mode Horaire, vérifiez que vous êtes dans l'un de vos créneaux

    Même principe. Un horaire ne s'applique que les jours et heures que vous avez définis ; en dehors de ces créneaux, YouTube est délibérément laissé tel quel. Si on est samedi et que votre horaire couvre les jours de semaine, rien ne sera masqué — c'est normal, ça fonctionne comme configuré.

Si vous voulez simplement que ce soit actif en permanence sans plus y penser, réglez le mode sur Toujours.

Un réglage fonctionnait puis a soudainement cessé

YouTube modifie assez souvent la structure de ses propres pages, et un changement de leur côté peut empêcher l'un des interrupteurs de trouver ce qu'il est censé masquer. C'est la cause la plus probable quand une seule fonctionnalité casse alors que les autres continuent de fonctionner.

Mieux vaut le signaler que d'attendre — c'est généralement vite corrigé une fois que l'on sait quelle partie de YouTube a changé. Précisez ce que vous regardiez et quel interrupteur a cessé de fonctionner.

Vous voulez retrouver YouTube normal pour un moment

Inutile de désinstaller ou de désactiver chaque option une par une. Ouvrez le popup, allez dans Mode et choisissez Désactivé. Tout réapparaît sur YouTube, et tous vos réglages et listes de blocage restent exactement tels que vous les avez laissés pour quand vous réactiverez l'extension.

Ce que FocusTube peut voir

Il ne fonctionne que sur les pages YouTube, et demande deux permissions : storage, pour mémoriser vos réglages, et alarms, pour les minuteurs et horaires du Mode Concentration. Il n'y a pas de compte, rien n'est envoyé où que ce soit, et rien de votre navigation n'est collecté.

L'extension est entièrement open source, donc c'est vérifiable plutôt qu'une simple promesse — lisez le code.

Toujours bloqué

Ouvrez un ticket (issue) sur GitHub et décrivez ce que vous attendiez et ce qui s'est passé à la place. Préciser votre version de navigateur et si vous êtes sur Windows, macOS ou Linux évite généralement un aller-retour.
